Search

Find anything in the museum.

We offer two forms of search for the museum: a semantic search covering the served documents themselves, and an advanced search covering the museum's registry edges.

Semantic Search: Search the Documents

What you type here is answered by the museum's host, Cloudflare AI Search.

Press Enter to search. wing: keeps to one wing (wing:nfw), class: to one kind of document (class:rp, card, news, roster, column). Try: "Seymour Almasy runs from bunnies"

Advanced Search: Search the Registry

Search the museum's internal graph explicitly: wings, characters, units, titles, shows, roleplays, essays, etc. Unlike semantic search, this operates exclusively in your browser.

Search Tips

Plain words still work as a substring search. A field:value token narrows to that field instead — e.g. promotion:uwf style:technician. Numeric fields also take >/</>=/<= (reigns:>3, opponents:>10 for who's fought the widest field), and every box speaks the full operator set — alternation, negation, presence/absence, ranges: search syntax. opponent: is the derived opponent-frequency join off data/shows.json's own match-by-match re-parse — opponent:"Al Crud" finds everyone who's faced him, once per match. language:/country: match by name as readily as by code — language:polish finds the same wing as language:pl, and language:!english (equivalently -language:english) finds every wing recorded outside the silent English default. Every field below is discovered from the registry's own data at page load — a new field the data grows tomorrow is queryable tomorrow, with nothing hand-wired here for it.
