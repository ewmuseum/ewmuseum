Throbbin Wood — Jan 20, 2010 at 3:42 PM When you join The IL, you start out with 100 Ranking Points (RP. Not to be confused with role playing). Here is how it works...
Victory = 3 points Time Limit Draw = 1 point each Loss = -2 points Disqualification = 1 point winner, -1 point loser Tag team matches will effect an individual's ranking points in the same way any match would. There won't be tag-specific ranking points because tag teams don't last forever or only last for one match.
