3-4 March 2007

Duke Williams — Mar 3, 2007 at 11:42 PM So after doing a simple web search I have found that Premier Championship wrestling is a real fed in Canada. http://www.pcwaction.com/ I'm not yet sure if I'm going to change the name of my fed, but I think it might be a good idea since I'm going to be running off of myspace and I don't want to confuse people to much.
So with that I'm open to suggestions to the name of this new Chicago based fed. I wanted to use the PCW initials as a homage to my favorite fed that I ever took part in and where most of Duke's history was made. But I can let go of the initials if somebody comes up with something better.
