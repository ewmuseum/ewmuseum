Submitting League Events

1 January 2008 (migration timestamp; not necessarily first written then)

Submitting League Events is intended to allow leagues to hype their latest events, show their activity, as well as receive basic feedback. League events can be submitted by a league fedhead, member or anyone designated to do so. 1. Log into the Content Manager and select “Submit League Event” from the main menu. 2. Fill out the form using the following tips: a. “League”: Choose the league you are submitting an event for. Note: the league must have filled out a league profile in order to be included in the list. b. “Subject”: This is the card name. The league acronym is NOT automatically added on the front, so you may want to include it. For example: CSWA ANNIVERSARY Celebration. c. “Main Event”: Enter the main event match to be highlighted here. Use “Other Info” to include any other matches or information about the card. d. “Event Logo”: Select a league event logo. If there is not one uploaded for your league, select the “default.jpg” option. To have a logo added, post a note in the “Fantasy Wrestling Discussion” area on FW Central at http://fwrestling.com/fwc. This can be modified even after you submit the event. e. “Event Date”: Be sure to enter the date in the MM.DD.YY format shown in the field. For example: 10.29.07. f. “Event Link to Site”: Include the link directly to the league event, starting with http:// 3. Upcoming Events: Currently, FW Central leagues and some affiliates have the ability to submit an event before it happens as an “upcoming event” that is featured on the Events page. If you would like to have access to this, have a good posting record and will commit to keeping it updated, please contact me on the boards or at [detail withheld] to discuss.
