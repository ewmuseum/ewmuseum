Chad — 08-03-02, 05:14 AM If you're long-time CSWA fans, welcome back. If you're first-time viewers, welcome as well.

We've added the Fan Interactive forums in order to get some feedback and continue to build the community here. As well as to look for potential members, of course.

In order to keep some security, we ask that you register in order to be able to post. "Fans" will be able to post in this forum and any other 'fan forums' that are set up. You can also view any of the roleplay or archived roleplay forums. The "General Discussion" forum is locked to CSWA members only, for 'housekeeping' reasons.

If you have questions about the CSWA, feel free to ask. If you want to talk about fantasy wrestling in general, do that too.

These forums are a test. If there's an interest in keeping them, we will. If only a few people are interested, we may come up with an alternative. But for now, use 'em, tell your friends, and let us know what you think.
