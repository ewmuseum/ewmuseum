What this is The profile page of Unforgiven on the UWF’s own site (cgi-bin/singles.cgi, name=unforgiven), as the Wayback Machine captured it: the profile (18 November 2004). The profile lists, as far as it was filled in, the wrestler’s vitals, theme music, hometown, biography, moveset and quotes, and a handler block; the handler’s name there reads first name and last initial, and the messenger names and e-mail addresses it prints are marked as withheld. The page’s navigation and background are not carried. The page itself carries no date.
