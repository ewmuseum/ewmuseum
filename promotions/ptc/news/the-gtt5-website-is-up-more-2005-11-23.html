http://gtt5.primetimecentral.net/index.php Special thanks to Matt W. for the image work (as well as all the individual poser artists whos work has been liberally borrowed). Site includes: - the formal rules (subject to enhancement as necessary!). - player biographies (linked off the bracket lists) - Resend login info to your email link (at the bottom of each player's bio) - official bracket names (if you're new here and don't get it, be patient... others will explain it to you) Still to come: - Hype and RP posting functionality (tomorrow night's task) - Player's ability to edit their own bio info (weekend task) - More quotes If you were one of the players that applied during the internet presale, your character description is missing. I need you to type it up again and send it to me ASAP. If you have a headshot and it doesn't appear in your bio now, let me know. The caveat there is that I don't use real people images - only posers, illustrations, cartoons etc. Enjoy! Aye... I'll put some sort of javascript prompt on it or something... tomorrow though..
