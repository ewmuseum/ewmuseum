I guess I'm going to have to stop saying that at the start of all these updates, because it seem's yall do good every week. I don't want to sound like a broken record. We had a few more guys join this week, but I am still looking for one more hardcore guy, and maybe another tag team. So yall be on the _LOOK OUT_ for that if ya don't mind. Were limited right now, but do have a few spots, mainly for next cycle. We got a good core, but I want to keep things fresh. The PPV is only a few weeks away and were gonna really start kicking it into high gear soon. Let's continue to pump out high quality work and see if we can't make this show something special. I believe that it can be. I know its our first one back so we won't have hit full stride by then, but damnit we can damn sure try to get to full stride that quick. Should be fun. We could use one more match writer for the PPV so if interested drop me a line, and we could also use one or two guys to help out on Fever here and there. So if you think you can do it hit me up. It won't be all the time, but it will be some of the time. That's all for now.
