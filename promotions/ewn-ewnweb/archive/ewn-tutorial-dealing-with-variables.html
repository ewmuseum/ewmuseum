Dealing w/ Variables (An intricate part of PHP programming) One of the awesome things about coding in PHP is the ability to use variables through entire scripts. Variables can make things within your scripts incredibly easy; and can save you alot of time when it comes to naming things.
This tutorial is mainly done within the actual code below; so just read the comments to understand what's going on. Below the code, I'll explain a little further on what's going on. 

<?PHP
	// These are where we declare the variables.

	// All variables MUST start out with the $ symbol.

	// Variables also follow the same format of the "echo" function, with the ";" at the end of the line.
	$name = "Rick";
	$age = "18";
	$haircolor = "Brown";

	// After we delcare the variables, now, we can use them!
	echo "Hello, my name is ".$name." and I am ".$age." with ".$haircolor." hair!";

	// You'll notice that the variables in the sentence are separated like so: "Hello, my name is ".$name." and I am ".$age." with ".$haircolor." hair!"

	// We do this because if we were to do it like this: "Hello, my name is $name and I am $age with $haircolor!", then the script wouldn't read the variables, and it would literally print $name, $age and $hair color instead of what we stored inside the actual variable.
?>
Using that code would give you: Hello, my name is Ricky and I am 18 with brown hair! You may still be wondering what the big deal about variables are. Well, say you wanted to refer to yourself more than one time throughout the entire script. Like so:

<?PHP
	// These are where we declare the variables.

	// All variables MUST start out with the $ symbol.

	// Variables also follow the same format of the "echo" function, with the ";" at the end of the line.
	$name = "Rick";
	$age = "18";
	$haircolor = "Brown";

	// After we delcare the variables, now, we can use them!
	echo "Hello, my name is ".$name." and I am ".$age." with ".$haircolor." hair!";

	// You'll notice that the variables in the sentence are separated like so: "Hello, my name is ".$name." and I am ".$age." with ".$haircolor." hair!"

	// We do this because if we were to do it like this: "Hello, my name is $name and I am $age with $haircolor!", then the script wouldn't read the variables, and it would literally print $name, $age and $hair color instead of what we stored inside the actual variable.

	// More code from the above text:
	echo "My first name is ".$name.".";
	echo "My friends call me ".$name.".";
	echo "You can call me ".$name.".";
	echo "The name on my birth certificate is ".$name.".";
?>

Now, let's say I change my name to Bob. If I didn't have the $name variable and I just wrote out "Rick" every place I have the variable at now, then I would have to go back into the script and change every single instance of "Rick" to "Bob".
Using the variables, I can just change the one line at the top that reads: $name = "Ricky"; ...to: $name = "Bob"; When you're editing something simple like the code mentioned above, it wouldn't be too bad to by-pass the use of variables; but whenever you get to entire scripts that have many, many lines of code, then it becomes very time consuming edit every instance of the variable without actually using it.
Hopefully you learned a little bit more about variables in PHP, and this can make alot of your programming much easier and quick.
