Introduction to PHP (The first thing you should know: PHP format.) PHP is becoming a very versatile and complex language, used by loads of different people. Web developers and scripters who have become adapted into many different languages are beginning to learn PHP as one of their primary languages; mainly because of it's ease of use and various useful functions.
When combined with the back-end power of MySQL (you'll learn about that a little later), PHP can put together complete communities and hosts of different people. The one thing that you'll learn about in this introduction is the standard format for using PHP.
Unlike HTML, PHP isn't what-you-see-is-what-you-get. PHP can be a bit difficult sometimes, and without including the smallest detail, such as a semi-colon or parenthesis, the entire script can go awry.
Standard Format The standard format for all PHP scripts comes in the documentation such as this: 
<?PHP
	echo "This is php code.";
?>
If you were to use that on a page on your server, the output would be: This is php code. The <?PHP begins the PHP code, the 'echo "this is php code";' tells the PHP script to echo the output into the browser, and then finally, the script is closed with ?>.
Remember that whenever you use echo's, the only two parenthesis that you can have are the ones starting and ending the text inside the echo. That is, unless you trick the PHP language, and include a small \ before each parenthesis mark that you want to actually be displayed. So, for instance:

<?PHP
	echo "This is "php" code.";
?>
...would produce errors. But, this: 
<?PHP
	echo "This is \"php\" code.";
?>
Would produce: This is "php" code. Understand? Good. Another thing to remember is that if you are going to want to begin coding in regular HTML again, you can either echo every line and worry about parenthesis, or you can do your page like this:

<?PHP
	// These are where we declare the variables.
	// All variables MUST start out with the $ symbol.
	// Variables also follow the same format of the "echo" function, with the ";" at the end of the line.
	$name = "Rick";
	$age = "18";
	$haircolor = "Brown";

	// After we delcare the variables, now, we can use them!
	echo "Hello, my name is ".$name." and I am ".$age." with ".$haircolor." hair!";

	// You'll notice that the variables in the sentence are separated like so: "Hello, my name is ".$name." and I am ".$age." with ".$haircolor." hair!"
	// We do this because if we were to do it like this: "Hello, my name is $name and I am $age with $haircolor!", then the script wouldn't read the variables, and it would literally print $name, $age and $hair color instead of what we stored inside the actual variable.
?>
This is going to produce not only the PHP code, but it's also going to print out the HTML. Read the comments if you aren't quite sure on how this works...
