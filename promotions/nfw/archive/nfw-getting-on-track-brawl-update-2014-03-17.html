17 March 2014

EastPrez — 17 March 2014 All - Hope everyone is good. I wanted to get some conversation going, as things have been pretty slow around here.
[detail withheld] and was hoping to see more activity but haven't seen much. I want to try and get the ship righted here, so a few things:
BRAWL71 should go up REAL SOON, hopefully within the beginning of the week. Apologies for the wait.
RP For RANDOM RUMBLE has been MAD thin, and I'm not happy with the handler output for the fed, or the fact that it's the first PPV we've done in almost a decade and I feel like I have to rattle the can when I ran this whole quarter to build up to this show. I'm happy for any handler activity and the writing that I have seen, but I really want to see more.
I know that we all slogged through the holiday season and then snowstorm upon snowstorm upon snowstorm on the east and midwest, (and we're supposed to get another tomorrow!) but we all need to get on the same page here.
I'm hoping to activate more RP for this PPV this week, and would like to put a RP deadline now for the show, of Saturday March 22nd, 11:59pm Midnight. After that, that's that.
Please make a push this week! Thanks guys.
