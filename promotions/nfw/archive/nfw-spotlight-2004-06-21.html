Off to Valinor — 21 June 2004 This will be a feature that you the handler will have much more control over Season II, but I'll start implementing our old-fashioned way this season.
With the playoffs coming up, I thought it'd be cool to see all those feel-good press articles about all the contending characters. But I don't have the time to write about it. Y'know something your agent might set up for you. ;)
Next Season, it'll be a little different...but for right now, if you want to write these up for your characters and send them to [detail withheld], I'll post them on the news site as a feature article.
These can be interviews, character pieces...rumours...heck, it doesn't have to be about 1 character. You can write about a feud, or upcoming matchup.
Anyway, I thought it'd be a good way to build up some storylines as well as really get the hype going and getting people excited for each coming week we get closer to Wrestlebowl.
[detail withheld] Peace.
