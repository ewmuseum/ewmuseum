EAW Application We are an e-fed that does not accept applications with real wrestlers. We will only accept applications with original wrestling characters. Thank you. Handler Name * E-mail Address: * Wrestler Name * Wrestlers Age * Height * Weight * Hometown * Years Experience * Entrance * please remember to include your characters theme song in the entrance and also be advised of EAW's limited budget. some pyros can be used, but try and limit entrances to smoke and coloured lighting. please note that EAW does use a video screen as well for entrances, etc. Wrestler Description * please include a description of your wrestler, including physical features and ring attire. try to be descriptive and dont say "he looks like this wrestler from this fed."
